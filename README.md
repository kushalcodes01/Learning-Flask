# Student Management System

A web-based Student Management System built using Flask, SQLite, HTML, CSS, and Jinja2.

## Features

- Add Student
- View Students
- Search Student
- Update Student
- Delete Student
- SQLite Database Integration
- Dynamic Flask Routes
- Jinja2 Templates
- Basic CSS Styling

## Technologies Used

- Python
- Flask
- SQLite
- HTML
- CSS
- Jinja2
- Git & GitHub
